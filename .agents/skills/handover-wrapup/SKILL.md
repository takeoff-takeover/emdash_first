# Handover & Wrap-up Workflow (作業終了・引き継ぎスキル)

ユーザーから作業終了や場所移動の指示（「明日のための準備して」「引き継ぎ」「まとめて」「帰宅するから準備して」など）を受けた際に、作業状態を確実にGitHubへPUT（同期）し、別環境でも即座に作業再開できるように以下のステップをワンストップで一括実行してください。

## 注意事項
* **Cloudflareへのデプロイ（`wrangler deploy`）は、明示的な指示がない限り勝手に行わないこと。**

## 実行ステップ

### 1. データベースのバックアップ
最新のCMS状態（ローカルD1の変更、追加記事、スキーマ変更）をエクスポートします：
```bash
npm run db:backup
```
* 出力された `seed/backup.sqlite` がコミット対象に含まれていることを確認します。

### 2. 引き継ぎ書の作成
プロジェクト直下に当日の日付を入れた引き継ぎ書（例: `HANDOVER-YYYY-MM-DD.txt`）を作成または更新します。

#### 記載フォーマット
```text
================================================================================
引き継ぎサマリー: YYYY-MM-DD
================================================================================

1. 今回のセッションで完了したこと
   - [完了項目1]
   - [完了項目2]

2. 現在のステータス & 積み残しタスク
   - [タスク名]: 現状の進捗と、次回着手すべき具体的なポイント
   - 注意点や検討事項

3. 次回環境（自宅／会社PC）での再開手順
   - プロジェクトフォルダに移動: cd ~/dev/my-emdash-site
   - 「開発準備して」と指示して dev-setup スキルを実行
================================================================================
```

### 3. GitHubへのアップロード（PUT）
1. `git status` で変更・追加されたファイルを確認します（コード、アセット、DBバックアップ、引き継ぎ書）。
2. 作業ツリーを整理し、コミットします：
   ```bash
   git add .
   git commit -m "chore: handover and db backup (YYYY-MM-DD)"
   ```
3. リモートへプッシュします：
   ```bash
   git push origin main
   ```

### 4. 完了報告
プッシュが成功したことを確認し、ユーザーに以下を簡潔に報告します：
* DBバックアップの完了
* 引き継ぎ書（`HANDOVER-YYYY-MM-DD.txt`）の作成完了
* GitHubへの同期（プッシュ）完了
* 次回再開時の最初のアクション案内
