3. 新しいPCでの環境構築・再開手順
   ----------------------------------------------------------------------------
   【Step 1】作業用ディレクトリでリポジトリをクローン
     cd ~/dev
     git clone https://github.com/takeoff-takeover/emdash_first.git my-emdash-site
     cd my-emdash-site

   【Step 2】プロジェクト直下に .env ファイルを作成
     以下の内容をプロジェクト直下の .env に保存します：
     --------------------------------------------------
     EMDASH_ENCRYPTION_KEY=emdash_enc_v1_S3w_iE-tZ3hg9LQ8bOPAk53mVcsWShscJwDIvvVDaJU
     EMDASH_TOKEN=ec_pat_cLzqhyseKpglYt1-CmmcdNw_e6fYG1Cv72R18htUSDk
     EMDASH_URL=https://my-emdash-site.kaz130.workers.dev

     # Google Maps / Places API Key
     GOOGLE_PLACES_API_KEY=AIzaSyCvALF5WExyVD0qx-LX8MV3xoyPYoKRX74
     --------------------------------------------------

   【Step 3】依存パッケージのインストール
     npm install

   【Step 4】ローカルデータベース（D1）の復元
     npm run db:restore --force

   【Step 5】開発サーバーの起動
     npm run dev
     * サイト: http://localhost:4321
     * 管理画面（認証バイパス直通）:
       http://localhost:4321/_emdash/api/auth/dev-bypass?redirect=/_emdash/admin

   ★ AIエージェント（Antigravity / Claude Code / Cursor等）を使用する場合：
     Step 1〜Step 2（クローンと .env 作成）を行った後、プロジェクトフォルダを開いて
     AIに「開発準備して」と指示するだけで、Step 3〜Step 5（パッケージ確認・DB復元・サーバー起動）を
     dev-setup スキルにより全自動で実行します。
