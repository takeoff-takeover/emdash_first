自宅での再開手順
1. 自宅のリポジトリに未保存変更があれば、先に別途保存する。
2. mainで git pull --ff-only origin main を実行する。
   初回は git clone https://github.com/takeoff-takeover/emdash_first.git を実行し、そのフォルダーへ移動する。
3. Node.js 24系とnpmが利用できる状態で npm ci を実行する。
   この作業環境はNode.js v24.22.1。Node標準のSQLiteを使用している。
4. 初回環境ではインストール時に seed/backup.sqlite からローカルDBが自動復元される。
   すでに自宅で起動済みの場合、自動復元は既存DBを上書きしない。
   最新の記事が出ない場合は、開発サーバーを停止し、自宅側の .wrangler/state/v3/d1 フォルダーを別の場所へバックアップしてから、
   .wrangler/state/v3/d1/miniflare-D1DatabaseObject 内のDB・WAL・SHMを一式退避する。
   続いて npm run db:restore を実行し、この引き継ぎの seed/backup.sqlite を復元する。
   自宅側で追加したCMS記事がある場合は、DBを置き換える前に差分を保存・確認すること。
5. npm run dev を実行し、上記URLを開く。
6. 記事の写真が5枚であること、赤いALPINAラベル、「出典・写真」欄を確認する。
